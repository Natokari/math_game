# 🎮 MATH ARCADE (Math Arcade & Portal Center)

A collection of offline, single-file math training games for elementary and middle school students. Designed to run smoothly in any browser on PC, tablets, and smartphones.

---

## 📂 Included Games / 収録ゲーム一覧

1. **FINAL FRACTION (`final_fraction.html`)**
   * **Content**: Fraction reduction slash battle. Use division commands (e.g., $\div 2$, $\div 12$) to reduce large fractions into their simplest form in an ATB (Active Time Battle) style.
   * **Feature**: Includes sector/central angle training modes (e.g., $60^\circ / 360^\circ$) essential for geometry.

2. **MAKE 10 PUZZLE (`make10_game.html`)**
   * **Content**: Classic puzzle where you combine 4 numbers using basic arithmetic ($+$, $-$, $\times$, $\div$) to make $10$.
   * **Feature**: Features consecutive calculations, inflation damage, and SSR color gacha.

3. **FRACTION MASTER (`fraction_game.html`)**
   * **Content**: Improper fraction $\rightleftarrows$ mixed fraction conversion speed battle.
   * **Feature**: Time attack format to break through mental conversion limits.

4. **FRACTION SNIPER (`fraction_sniper_game.html`)**
   * **Content**: Convert improper fractions to mixed numbers and snipe targets on a number line in two precise steps.

---

## 💻 How to Play / 遊び方

1. Create an empty HTML file (e.g., `final_fraction.html`) on your computer.
2. Copy the entire source code of the desired game and paste it into the HTML file.
3. Double-click the file to open it in any browser (Chrome, Edge, Safari) and play completely offline!
